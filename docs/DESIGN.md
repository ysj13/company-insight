# 디자인 기준

기업 인사이트의 모든 화면(종목 화면, 운영자 페이지, 이후의 홈·랜딩)이 따르는 규칙이다. 기준 화면은 `demo.html`이고, 실제 화면(Thymeleaf)은 이 문서의 토큰과 규칙을 그대로 옮긴다. 규칙을 바꾸면 이 문서와 데모를 함께 고친다.

## 0. 분위기

**다크, 테크, AI, 모던, 심플, 가독성, 글래스모피즘.** 색은 무채색(살짝 차가운 회색 계열)만 쓰고, 뜻이 있는 색은 호재(빨강)·악재(파랑)·AI(보라) 셋뿐이다. **검정·회색은 한 계열의 회색 단계표(3-1) 중 하나만 써서 화면 전체의 검정이 같은 톤으로 보이게 한다.** 바탕은 거의 검정 한 색이고(빛·격자·무늬 없음), 카드는 한 단계 밝은 면에 가는 회색 테두리, 카드 안의 칸과 버튼은 또 한 단계 밝은 면이다. 유리(뒤를 흐리는 반투명)는 위에 떠 있는 상단 바와 공시 패널에만 쓴다. 글자와 판단 표시는 언제나 단단하고 또렷하게 둔다. 효과와 가독성이 부딪히면 가독성이 이긴다.

## 1. 원칙

1. **판단과 근거가 먼저 읽힌다.** 화면에서 가장 크고 진한 것은 판단 단계 이름이고, 그다음이 근거 공시다. 장식은 이 순서를 흐리지 않는다.
2. **AI는 근거와 함께 말한다.** AI가 한 일(요약, 판정)은 보라색으로 표시하고, 바로 옆에 원문 링크나 판정 방법을 둔다.
3. **매일 봐도 피곤하지 않다.** 순수 검정과 순수 흰색을 쓰지 않고, 움직이는 연출 대신 상태가 바뀐 것을 알리는 반응만 둔다.
4. **한눈에 들어온다.** 한 줄에는 한 가지 말만 한다. 쉬운 말이 먼저이고, 원문과 세부 정보는 그 아래나 공시 패널로 보낸다.

## 2. 화면 종류별 효과 수준

| 화면 | 효과 |
|---|---|
| 랜딩 (MVP 이후) | 연출 허용(빛줄기, 반투명 카드, 들어올 때 나타나는 움직임). 연출은 이 화면에만 쓴다 |
| 일반 화면 (종목 화면, 홈) | 위에 떠 있는 유리(상단 바, 공시 패널) + 상태 반응(색 전환, 패널 열림, 새 항목 밝힘) |
| 작업 화면 (운영자 페이지) | 유리 없이 같은 회색 단계표의 불투명 면만. 효과 없음 |

## 3. 색

**색은 모두 토큰으로만 쓴다.** 컴포넌트에 `#fff`나 `rgba(255,255,255,…)`를 직접 쓰지 않는다. 라이트 모드를 붙일 때 토큰 블록 하나만 더하면 되게 하려는 것이다.

### 3-1. 회색 단계표와 토큰

**검정·회색은 아래 단계표의 값만 쓴다.** 모두 같은 계열(살짝 차가운 회색)이라 어디에 놓여도 같은 톤으로 보인다. 반투명 흰 빛을 겹쳐 회색을 만들지 않는다(겹치는 바탕에 따라 톤이 달라진다).

| 단계 | 값 | 역할 |
|---|---|---|
| `--g950` | `#09090b` | 바탕(거의 검정. 순수 검정 위 순수 흰색은 글자가 번져 보여 둘 다 한 단계씩 낮춘다) |
| `--g925` | `#111113` | 카드, 판단 카드 |
| `--g900` | `#18181b` | 카드 안의 칸, 입력창, 버튼, hover |
| `--g800` | `#27272a` | 테두리·줄 나눔, 누름·선택, 중립 면, 막대 바닥 |
| `--g700` | `#3f3f46` | 버튼 테두리, hover 테두리, 판단 카드 테두리 |
| `--g600` | `#52525b` | 선택 테두리, 판단 카드 윗변 |
| `--g450` | `#93939c` | 가장 옅은 글씨(날짜, 출처, 설명) |
| `--g400` | `#a1a1aa` | 보조 글씨, 중립 |
| `--g200` | `#e4e4e7` | 본문, 제목(순수 흰색을 쓰지 않는다) |

면은 안으로 들어갈수록 한 단계씩 밝아진다: 바탕 950 → 카드 925 → 카드 안의 칸 900 → 선택 800.

| 토큰 | 값 | 쓰는 곳 |
|---|---|---|
| `--bg` / `--card` / `--surface` / `--btn` | 950 / 925 / 900 / 900 | 바탕 / 카드 / 카드 안의 칸(반대로 볼 점, 날짜 목록, 실적 칸, 패널의 칸), 입력창 / 버튼 |
| `--text` / `--text-sub` / `--text-faint` | 200 / 400 / 450 | 본문 / 보조 글씨, 칸 제목, DART 원문 제목 / 날짜·출처·설명 |
| `--line` / `--line-hover` / `--line-selected` / `--line-strong` | 800 / 700 / 600 / 700 | 카드 테두리·줄 나눔 / 버튼 테두리·hover / 선택 / 판단 카드 테두리 |
| `--fill-hover` / `--fill-selected` | 900 / 800 | hover 배경 / 누름·선택 배경 |
| `--glass-solid` | 950을 80%로 + 뒤 흐림 24px | 위에 떠 있는 유리(상단 바, 공시 패널) |
| `--focus` | 흰색 60% | 키보드 포커스 테두리 |
| `--up` / `--up-soft` / `--up-line` | `#ff5c69` / 12% / 45% | 호재 / 칩·배지 면 / 배지 테두리 |
| `--down` / `--down-soft` / `--down-line` | `#4c94ff` / 12% / 45% | 악재 / 칩·배지 면 / 배지 테두리 |
| `--flat` / `--flat-soft` | 400 / 800 | 중립 |
| `--ai` / `--ai-soft` | `#a78bfa` / 12% | AI가 한 일 / AI 칩 면 |
| `--ai-wash` / `--ai-line` | 보라 6% / 32% | AI가 쓴 글을 담는 칸의 면 / 테두리 |
| `--scrim` | 검정 55% | 패널이 열렸을 때 뒤 화면을 덮는 막 |

### 3-2. 색의 뜻

- **빨강은 호재, 파랑은 악재, 회색은 중립**이다. 이 세 색은 이 뜻으로만 쓴다(오류, 경고, 링크에 쓰지 않는다).
- **색만으로 구분하지 않는다.** 호재·악재 표시에는 항상 모양(▲ 호재, ▼ 악재, — 중립)과 글자를 함께 붙인다.
- **보라는 AI가 한 일에만** 쓴다: "AI 요약" 칩, AI가 쓴 글의 칸(판단 카드의 한 줄 요약, 공시 패널의 3줄 요약은 옅은 보라 면 + 보라 테두리 칸에 넣는다), "AI 판정" 표시. 선택 상태, 링크, 강조, 그래프에는 쓰지 않는다. 빨강과 파랑이 겹쳐 보라처럼 보이는 곳도 만들지 않는다.
- **선택된 탭·버튼은 흰색**(`--text` 바탕에 `--bg` 글자)이다. 강조색을 따로 두지 않는다.
- 초록(해외에서 상승을 뜻함)과 노랑(경고로 읽힘)은 쓰지 않는다.
- 판단 추이 그래프의 선 색은 판단 단계의 경계를 따른다. 약한 호재 경계 위는 빨강, 약한 악재 경계 아래는 파랑, 그 사이(중립)는 회색이다.
- 호재·악재 칩, AI 칩, 배지는 불투명한 `--card` 위에 겹친 색으로 고정한다. 선택된 줄 위에 올라가도 글자 대비가 변하지 않게 하려는 것이다.
- 바탕과 면, 선은 회색 단계표만 쓴다. 바탕에 빛·그라데이션·무늬를 깔지 않는다.
- 판단 배지는 옅은 색 면(`--up-soft` 등)에 가는 색 테두리를 두르고, 강한 호재·악재만 색으로 채운다.

### 3-2-1. 유리를 쓰는 규칙

- 유리는 **위에 떠 있는 것**(상단 바, 공시 패널)에만 쓴다: 바탕색(950) 80% + 뒤 흐림 24px. 스크롤하는 글이 그 아래로 지나갈 때 흐리게 비친다.
- 카드, 칩, 배지, 버튼, 카드 안의 칸, 자동완성 목록은 불투명한 회색 단계 면이다. 유리 위에 유리를 겹치지 않는다.
- 카드의 테두리는 1px `--line`이고, 판단 카드만 2px `--line-strong`에 윗변을 한 단계 밝게(`--line-selected`) 한다. 그림자는 쓰지 않는다.
- AI 칩에만 아주 옅은 보라 빛(바깥 번짐 14px)을 둔다. 다른 요소에는 빛 번짐을 쓰지 않는다.
- 유리를 못 쓰는 브라우저와 "투명도 줄이기"를 켠 사용자에게는 상단 바와 패널을 불투명한 바탕색으로 보여준다.

### 3-3. 대비 (WCAG 식으로 계산한 값)

| 조합 | 대비 |
|---|---|
| 본문 `--text` / 바탕, 카드, 안쪽 칸, 선택된 줄 | 15.7, 14.9, 14.0, 11.7 : 1 |
| 보조 `--text-sub` / 바탕, 카드, 안쪽 칸, 선택된 줄 | 7.8, 7.4, 6.9, 5.8 : 1 |
| 옅은 글씨 `--text-faint` / 바탕, 카드, 안쪽 칸, 선택된 줄 | 6.5, 6.2, 5.8, 4.9 : 1 |
| 호재 빨강·악재 파랑 / 바탕, 카드, 안쪽 칸, 칩·배지 면 | 6.6, 6.3, 5.9, 5.4 : 1 |
| AI 보라 / 카드, 안쪽 칸, AI 칩 | 6.9, 6.5, 5.9 : 1 |
| AI가 쓴 글의 칸 위 본문, 옅은 글씨, 보라 | 13.5, 5.7, 6.3 : 1 |
| 강한 호재·악재 배지(색 바탕에 바탕색 글자) | 6.6 : 1 |

- 본문 대비를 14 ~ 16 : 1로 둔다. 20 : 1이 넘으면(순수 검정 위 순수 흰색) 글자가 번져 보이고 눈이 피곤하다.
- 빨강과 파랑은 밝기가 같아서(상대 휘도 0.299) 어느 한쪽이 더 눈에 띄지 않는다.
- 새 조합을 만들면 그 바탕 위에서 다시 계산하고, 글자는 4.5 : 1 이상을 지킨다. 분석 실패 때 흐리게 보이는 지난 판단(투명도 .6)만 예외다.

## 4. 글자

- 글꼴: Pretendard(가변 굵기). 한글과 영문·숫자의 모양이 고르고 화면용으로 만들어져 모던·테크 분위기에 맞는다. 없으면 시스템 글꼴(-apple-system, Apple SD Gothic Neo, 맑은 고딕) 순서다. 실제 화면에서는 글꼴 파일을 직접 두고 쓴다.
- 크기: 13(설명·메타) / 15(본문) / 17(카드 제목, 강조 본문) / 20(판단 배지, 패널 제목) / 24(폭 600px 이하의 회사 이름) / 28(회사 이름) / 44(랜딩 전용)px. 이 밖의 크기는 쓰지 않는다.
- 굵기: 400(본문) / 500(타임라인의 줄) / 700(판단 근거의 줄, 칸 제목, 라벨) / 800(판단 배지, 회사 이름, 패널 제목).
- 한 카드 안의 글자 위계는 세 단계까지다: 제목 / 본문 / 보조. 보조는 13px 회색 한 줄로 모은다.
- 줄 간격 1.6, 자간 −0.01em(큰 제목은 −0.02 ~ −0.03em).
- 숫자는 `tabular-nums`로 자리를 맞춘다.
- 금액은 읽기 쉬운 단위로 쓴다: 1조 원 이상은 "237.3조", "1.63조"(소수 둘째 자리까지), 그 아래는 "3,900억". "2,373,000억"처럼 쓰지 않는다.
- 한글은 `word-break: keep-all`로 단어 중간에서 줄을 바꾸지 않고, 긴 공시 제목은 `overflow-wrap: anywhere`로 넘치지 않게 한다.
- 공시 제목은 DART 원문 그대로 쓴다. 줄이거나 고치지 않는다. 다만 목록과 패널의 주인공은 쉬운 말 한 줄이고, 원문 제목은 그 아래 보조 줄에 둔다(8절).

## 5. 모양과 간격

- 둥근 모서리: 카드 16px, 버튼·입력창 10px, 카드 안의 칸 12px, 호재·악재 칩 6px, 배지·세그먼트 버튼 999px.
- **묶음은 면으로 나눈다.** 카드는 회색 단계 925 면이고 테두리는 1px `--line`뿐이다. 카드 안의 칸은 `--surface` 면으로 한 단계 들인다. 그 밖의 선은 목록의 줄 나눔(`--line`)에만 쓴다.
- **2px 테두리는 판단 카드만** 쓴다(화면의 기준점). 왼쪽 세로 막대 장식은 쓰지 않는다.
- 레이아웃: 폭 1100px 미만은 한 열(최대 폭 720px), 1100px 이상은 두 단(최대 폭 1160px, 왼쪽 판단 카드 460px, 오른쪽 나머지, 사이 24px). 양옆 여백 16px 이상(노치가 있는 기기는 안전 영역만큼 더). 카드 사이 20px, 카드 안 여백 24px(폭 600px 이하에서는 20 / 16px), 목록 한 줄의 위아래 여백 14px.

## 6. 상태

**누를 수 있는 것** (실제 `button`, `a`만 쓴다)

| 상태 | 표현 |
|---|---|
| 기본 | 배경 없음 또는 `--line` 테두리 |
| hover | 배경 `--fill-hover`, 테두리 `--line-hover` |
| 누름·선택(패널에 열린 줄 포함) | 배경 `--fill-selected` |
| 포커스 | 2px `--focus` 테두리, 3px 띄움. **절대 빼지 않는다** |
| 쓸 수 없음 | 투명도 .4, 커서 기본 |

- 누를 때 크기를 바꾸지 않는다(scale, 이동 없음). 배경과 테두리 색만 바뀐다.
- 누를 수 없는 카드에는 hover를 두지 않는다.
- 누르면 무언가 열리는 줄에는 끝에 `›`를, 바깥(DART)으로 나가는 링크에는 `↗`를 붙인다. 접고 펴는 것은 아래 화살표가 돈다.

**판단 카드의 상태 다섯 가지**: 호재 / 악재 / 중립 / 판단 보류(배지와 카드 테두리를 점선으로) / 분석 실패(지난 판단을 투명도 .6으로 흐리게 보여주고, 원인 한 줄과 "다시 불러오기" 버튼).

**비어 있거나 없는 것은 이유를 말한다.** "이날 들어온 공시는 없어요", "중립 공시는 요약하지 않아요", "요약을 아직 만들지 않았어요. 다음 분석 때 채워져요"처럼 왜 없는지와 언제 생기는지를 쓴다.

## 7. 움직임

- 기본 전환: 0.2초, `cubic-bezier(0.4, 0, 0.2, 1)`. 이 하나만 쓴다.
- 쓰는 곳: 색·테두리 전환, 접기 화살표 회전, 패널 열림(오른쪽에서 밀려 들어옴, 시트는 아래에서), 막 나타남, 새로 들어온 항목을 1.2초 밝혔다가 원래대로.
- 쓰지 않는 것: 크기 변화, 흔들림, 튀는 곡선, 스크롤에 따라 움직이는 연출, 저절로 도는 슬라이드, 숫자 올라가는 효과.
- 사용자가 움직임 줄이기(`prefers-reduced-motion`)를 켜 두었으면 전환과 애니메이션을 모두 끈다.

## 8. 화면 패턴

- **종목 화면은 위에서 아래로 한 줄 흐름**이다: 회사 이름 → 판단 카드 → 판단 추이 → 실적(접힘) → 타임라인. 넓은 화면에서는 회사 이름 아래 왼쪽에 판단 카드, 오른쪽에 판단 추이·실적·타임라인을 둔다. 판단 카드는 화면에 고정하지 않는다(카드가 화면보다 길면 카드 안에 스크롤이 하나 더 생겨 불편하다).
- **카드 제목은 짧은 명사형**이다: "판단 추이", "실적", "타임라인". 질문형("…어때요?")을 쓰지 않는다.
- **로고:** 모서리가 둥근 사각 칸(30px, 모서리 9px)을 `--text` 면으로 채우고, 겹친 층 아이콘을 `--bg` 색으로 넣는다. 옆에 "기업 인사이트".
- **상단 바:** 로고와 검색창. 검색창은 최대 폭 420px이고 넓은 화면에서도 끝까지 늘리지 않는다.
- **회사 머리:** 회사 이름이 먼저, 그 아래 한 줄에 종목코드 · 시장 · 업종. 판단 카드와 떨어뜨린다.
- **판단 막대:** 막대 양 끝에 "악재"와 "호재"만 작게 붙인다. 가운데(중립)는 막대의 홈으로 보인다.
- **그래프:** 점선 격자를 쓰지 않는다. 판단 추이는 중립 구간만 옅은 띠로 깔고, 이름표는 호재·중립·악재 셋이다. 판단 보류 기간(호재·악재 공시가 없던 날이 이어진 구간)은 선을 회색 점선으로 그려 중립과 구분한다. 점선은 이 뜻으로만 쓴다. 이름표와 설명은 그래프 밖(오른쪽 끝, 아래 안내 한 줄)에 둔다.
- **공시 한 줄(판단 근거, 타임라인, 날짜 목록)은 두 줄로 쓴다.**
  - 첫 줄: 무슨 일인지 쉬운 말 한 줄. 사실만 쓴다("3분기 영업이익이 1년 전보다 13% 증가", "자기주식 3조 원 취득 결정"). 판정 이유("호재로 정한 유형이라")는 쓰지 않는다.
  - 둘째 줄(13px 회색): 날짜 · DART 원문 제목. AI가 판정한 공시만 끝에 보라색 "AI 판정"을 붙인다.
  - 공시 유형, 크기, 판정 방법, 요약은 목록에 쓰지 않고 공시 패널에서 보여준다.
  - **칩은 한 줄에 하나까지**(호재·악재). 폭 600px 이하에서는 칩을 모양(▲ ▼ —)만 남기고 "호재·악재" 글자는 화면 읽기 프로그램용으로 숨겨, 쉬운 말 한 줄이 꺾이지 않게 한다. 타임라인은 선 위의 모양(▲ ▼ ●)이 그 역할을 하므로 칩을 붙이지 않는다(화면 읽기 프로그램용 글자는 숨겨서 붙인다).
- **설명 문단은 접는다.** 판단 카드의 계산 방식은 "계산 방식"을 눌러야 보인다. 고지 한 줄은 늘 보인다.
- **탭은 쓰지 않는다.** 정보가 많으면 덜 중요한 것을 접는다(나머지 근거, 실적, 계산 방식). 기간처럼 같은 내용을 다른 범위로 보는 선택만 세그먼트 버튼으로 둔다.
- **공시 한 건은 공시 패널로 연다.** 화면 오른쪽에서 열리는 폭 440px 패널이고, 폭 640px 이하에서는 아래에서 올라오는 시트(화면 높이의 88%까지)다. 어디서 누르든 같은 패널이 열린다.
  - 패널 내용 순서: 호재·악재와 크기, 날짜·유형 → 제목(쉬운 말 한 줄) → DART 원문 제목 → 지금 판단에 들어가 있는지 → AI 3줄 요약 → 어떻게 판정했나 → DART 원문 링크 → 고지.
  - 열면 포커스가 닫기 버튼으로 가고 뒤 화면은 누를 수 없게 막는다. Esc, 바깥 막 누르기, 닫기 버튼, 뒤로 가기로 닫힌다. 닫으면 포커스가 누른 줄로 돌아간다.
  - 패널이 열린 동안 그 공시의 줄은 선택 상태로 보인다.
  - 공시마다 주소(접수번호)가 붙는다. 패널 안의 이전·다음은 주소를 바꾸기만 하고 뒤로 가기 기록을 쌓지 않는다.
- **소식은 세로 타임라인**으로 보여준다: 다가오는 일정 → 오늘 → 지난 공시. 선 위의 표시도 모양(▲ ▼ ● ○)으로 구분한다.
- 숫자 점수는 공개 화면에 보이지 않는다. 판단은 다섯 단계 이름과 수평 막대로 보여준다.

## 9. 접근성

- 글자 대비 4.5 : 1 이상(3-3).
- 손가락으로 누르는 기기에서 누르는 곳은 44px 이상이다.
- 누르는 것은 실제 `button`과 `a`로 만든다. `div`에 클릭을 달지 않는다.
- 그래프는 키보드(좌우 방향키)로도 날짜를 옮길 수 있고, 같은 내용을 글로도 보여준다.
- 색만으로 뜻을 전하지 않는다(3-2).

## 10. 문구

- 해요체로 쓴다. 짧게, 사실만. 목록의 쉬운 말 한 줄은 명사로 끝내도 된다("…13% 증가", "…취득 결정").
- 매수·매도·추천·목표가·예측처럼 읽히는 표현과 시세를 안내하는 표현을 쓰지 않는다.
- 판단은 "최근 공시 기준"으로 범위를 밝힌다.
- 오류는 원인과 다음 행동을 쓰고 사과하지 않는다. 예: "11.06 공시 분석이 끝나지 않아 11.05 판단을 보여주고 있어요. 새 공시는 다음 분석 때 반영돼요."
- 판단 카드, 공시 패널, 화면 아래에 "AI 요약은 틀릴 수 있으며 투자 권유가 아니에요" 고지를 둔다. 공시·재무의 출처(DART)를 밝힌다.

## 11. 라이트 모드 (이후)

지금은 어두운 토큰 한 벌만 있다(`color-scheme: dark`). 라이트 모드는 3-1의 토큰 블록을 하나 더해 붙인다(회색 단계표를 밝은 쪽으로 뒤집고, 호재·악재·AI 색은 밝은 바탕에서 대비를 다시 계산한다). 시스템 설정을 따를지 전환 버튼을 둘지는 붙일 때 정한다.
