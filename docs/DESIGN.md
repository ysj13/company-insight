# 디자인 기준

기업 인사이트의 모든 화면(종목 화면, 운영자 페이지, 이후의 홈·랜딩)이 따르는 규칙이다. 기준 화면은 `demo.html`이고, 토큰·부품·상태·아이콘을 한 페이지에 모은 것은 `design-system.html`이다. 실제 화면(Thymeleaf)은 이 문서의 토큰과 규칙을 그대로 옮긴다. 규칙을 바꾸면 이 문서와 두 페이지를 함께 고친다(두 페이지의 토큰과 부품 CSS는 같은 내용이다).

## 0. 분위기

**다크, 테크, AI, 모던, 심플, 가독성, 글래스모피즘.** 색은 무채색(살짝 차가운 회색 계열)만 쓰고, 뜻이 있는 색은 호재(빨강)·악재(파랑)·AI(보라) 셋뿐이다. 재무 그래프 안의 지표 색만 예외다(3-4). **검정·회색은 한 계열의 회색 단계표(3-1) 중 하나만 써서 화면 전체의 검정이 같은 톤으로 보이게 한다.** 바탕은 거의 검정 한 색이고(빛·격자·무늬 없음), 카드는 한 단계 밝은 면에 가는 회색 테두리, 카드 안의 칸과 버튼은 또 한 단계 밝은 면이다. 유리(뒤를 흐리는 반투명)는 위에 떠 있는 상단 바와 패널에만 쓴다. 글자와 판단 표시는 언제나 단단하고 또렷하게 둔다. 효과와 가독성이 부딪히면 가독성이 이긴다.

## 1. 원칙

1. **판단과 근거가 먼저 읽힌다.** 판단은 회사 이름 바로 옆에 색 글자로 두어 어느 탭에서든 보이고, 처음 열리는 탭(공시)이 그 근거(AI 요약과 최근 공시)다. 장식은 이 순서를 흐리지 않는다.
2. **AI는 근거와 함께 말한다.** AI가 쓴 글은 보라색 칸에 넣고, 공시 패널에서는 바로 위에 DART 원문 링크를 둔다.
3. **매일 봐도 피곤하지 않다.** 순수 검정과 순수 흰색을 쓰지 않고, 움직이는 연출 대신 상태가 바뀐 것을 알리는 반응만 둔다.
4. **한눈에 들어온다.** 비슷한 자료끼리 묶는다(공시 · 개요 · 재무 · 뉴스). 한 사실은 한 자리에만 둔다. 한 줄에는 한 가지 말만 하고, 요약과 세부 정보는 패널로 보낸다.
5. **작은 회색 설명 문장을 화면에 두지 않는다.** 화면에 남는 작은 글씨는 라벨, 데이터(날짜·출처·기준), 필수 고지뿐이다. 읽는 법을 알려 주는 문장이 필요하면 모양을 고친다.

## 2. 화면 종류별 효과 수준

| 화면 | 효과 |
|---|---|
| 랜딩 (MVP 이후) | 연출 허용(빛줄기, 반투명 카드, 들어올 때 나타나는 움직임). 연출은 이 화면에만 쓴다 |
| 일반 화면 (종목 화면, 홈) | 위에 떠 있는 유리(상단 바, 패널) + 상태 반응(색 전환, 패널 열림, 새 항목 밝힘) |
| 작업 화면 (운영자 페이지) | 유리 없이 같은 회색 단계표의 불투명 면만. 효과 없음 |

## 3. 색

**색은 모두 토큰으로만 쓴다.** 컴포넌트에 `#fff`나 `rgba(255,255,255,…)`를 직접 쓰지 않는다. 라이트 모드를 붙일 때 토큰 블록 하나만 더하면 되게 하려는 것이다.

### 3-1. 회색 단계표와 토큰

**검정·회색은 아래 단계표의 값만 쓴다.** 모두 같은 계열(살짝 차가운 회색)이라 어디에 놓여도 같은 톤으로 보인다. 반투명 흰 빛을 겹쳐 회색을 만들지 않는다(겹치는 바탕에 따라 톤이 달라진다). 상단 바의 옅은 흰 기운과 밝은 테두리(3-2-1)만 예외다.

### 3-2. 색의 뜻

- **빨강은 호재, 파랑은 악재, 회색은 중립**이다. 이 세 색은 이 뜻으로만 쓴다(오류, 경고, 링크에 쓰지 않는다). 재무 수치의 증감(1년 전 대비 +·−)도 같은 빨강·파랑이다.
- **색만으로 구분하지 않는다.** 호재·악재·중립 표시에는 항상 "호재", "악재", "중립" 글자를 함께 쓴다(판단 이름, 칩, 타임라인 날짜 줄). **▲·▼ 같은 모양 기호는 쓰지 않는다.** 빨강 ▲·파랑 ▼는 주가 등락 표시와 같아 판단이 시세처럼 읽히고, 작은 기호는 가독성이 떨어진다. 뜻은 글자가 전한다.
- **보라는 AI가 한 일에만** 쓴다: AI가 쓴 글의 칸(공시 탭의 AI 요약 카드, 공시 패널의 3줄 요약은 옅은 보라 면 + 보라 테두리이고, 칸 위쪽에 작은 보라 글자 "AI 요약"을 이름표로 단다. 칸 안에 칩을 또 넣지 않는다). 선택 상태, 링크, 강조에는 쓰지 않는다. 빨강과 파랑이 겹쳐 보라처럼 보이는 곳도 만들지 않는다.
- **선택된 탭·버튼은 흰색**이다(탭은 흰 글자 + 흰 밑줄, 세그먼트는 `--text` 바탕에 `--bg` 글자). 강조색을 따로 두지 않는다.
- 초록(해외에서 상승을 뜻함)과 노랑(경고로 읽힘)은 뜻 색으로 쓰지 않는다. 재무 그래프의 청록·호박은 지표 이름표일 뿐이다(3-4).
- 호재·악재 칩은 불투명한 `--card` 위에 겹친 색으로 고정한다. 선택된 줄 위에 올라가도 글자 대비가 변하지 않게 하려는 것이다.
- 바탕과 면, 선은 회색 단계표만 쓴다. 바탕에 빛·그라데이션·무늬를 깔지 않는다.
- **판단 이름(약한 호재 등)은 회사 이름 옆에 색 글자로만 쓴다.** 호재는 빨강, 악재는 파랑, 중립은 본문색, 판단 보류는 보조색이다. 상자·알약·단계 눈금을 두르지 않는다. 상자를 두르면 버튼처럼 보이고, 강한·약한은 글자가 이미 말한다.

### 3-2-1. 유리를 쓰는 규칙

- 유리는 **위에 떠 있는 것**(상단 바, 패널)에만 쓴다. 스크롤하는 글이 그 아래로 지나갈 때 흐리게 비친다.
  - 상단 바: 바탕색(950) 45% + 옅은 흰 기운 4% + 뒤 흐림 24px(채도 180%), 아래 테두리는 흰색 10%. 검색창도 흰색 6% 면에 같은 테두리.
  - 패널: 바탕색 80% + 뒤 흐림 24px. 글을 오래 읽는 곳이라 상단 바보다 덜 비친다.
- 카드, 칩, 버튼, 카드 안의 칸, 자동완성 목록, 탭 줄은 불투명한 회색 단계 면이다. 유리 위에 유리를 겹치지 않는다. 탭 줄은 상단 바 아래에 붙어 따라오지만 바탕색(950) 불투명 면이라 글자가 겹쳐 비치지 않는다.
- **AI 요약 카드도 단색이다.** 반투명 카드는 뒤에 무엇이 지나가느냐에 따라 면의 밝기가 바뀌어 옅은 글씨의 대비가 떨어진다.
- 카드의 테두리는 1px `--line`이고, AI 요약 카드만 1px `--ai-line`이다. 그림자는 쓰지 않는다.
- 빛 번짐(글로)은 쓰지 않는다.
- 유리를 못 쓰는 브라우저와 "투명도 줄이기"를 켠 사용자에게는 상단 바와 패널을 불투명한 바탕색으로 보여준다.

### 3-3. 대비 (WCAG 식으로 계산한 값)

`design-system.html`이 토큰 값으로 직접 계산해 보여준다(반투명 색은 아래 면에 합성해서 계산).

| 조합 | 대비 |
|---|---|
| 본문 `--text` / 바탕, 카드, 안쪽 칸, 선택된 줄, 보조 버튼 누름 | 15.7, 14.9, 14.0, 11.7, 8.2 : 1 |
| 보조 `--text-sub` / 바탕, 카드, 안쪽 칸, 선택된 줄 | 7.8, 7.4, 6.9, 5.8 : 1 |
| 옅은 글씨 `--text-faint` / 바탕, 카드, 안쪽 칸, 선택된 줄 | 6.5, 6.2, 5.8, 4.9 : 1 |
| 주 버튼 글자 `--on-primary` / 기본, hover, 누름 | 15.7, 13.5, 7.8 : 1 |
| 호재 빨강·악재 파랑 / 바탕(판단 이름), 카드, 안쪽 칸, 선택된 줄, 칩 면 | 6.6, 6.3, 5.9, 5.0, 5.4 ~ 5.5 : 1 |
| AI 보라 / 카드, 안쪽 칸, AI가 쓴 글의 칸 | 6.9, 6.5, 6.4 : 1 |
| AI가 쓴 글의 칸 위 본문, 옅은 글씨 | 13.8, 5.8 : 1 |
| 그래프 색 / 카드 (그림이라 3 : 1 기준) | 파랑 5.2, 청록 5.5, 호박 6.1, 보라 6.0, 주황 4.9, 비율 선 12.8 : 1 |
| 포커스 테두리 / 바탕, 카드 (선이라 3 : 1 기준) | 7.3, 7.2 : 1 |

- **보조 글씨를 `--g700` 면 위에 쓰지 않는다**(4.1 : 1). 보조 버튼을 누를 때(700 면)는 글자가 본문색이라 괜찮다.
- 본문 대비를 14 ~ 16 : 1로 둔다. 20 : 1이 넘으면(순수 검정 위 순수 흰색) 글자가 번져 보이고 눈이 피곤하다.
- 빨강과 파랑은 밝기가 같아서(상대 휘도 0.299) 어느 한쪽이 더 눈에 띄지 않는다.
- 새 조합을 만들면 그 바탕 위에서 다시 계산하고, 글자는 4.5 : 1 이상을 지킨다. 분석 실패 때 흐리게 보이는 지난 요약(투명도 .6), 쓸 수 없는 상태(투명도 .4, WCAG 예외), 주주 구성 막대의 "그 밖의 주주" 칸(`--g600`, 2.4 : 1. 바로 아래 범례에 이름과 숫자가 있다)만 기준 밖이다.

### 3-4. 그래프 색

- **지표마다 색을 고정한다.** 같은 지표는 어느 그래프에서나 같은 색이다. 그래프 하나 안에서 색을 돌려 쓰지 않는다.

| 지표 | 토큰 | 값 |
|---|---|---|
| 매출액 | `--vz-blue` | `#3987e5` |
| 순이익 | `--vz-teal` | `#199e70` |
| 영업이익 | `--vz-amber` | `#c98500` |
| 총자본 | `--vz-violet` | `#9085e9` |
| 총부채 | `--vz-orange` | `#d95926` |
| 비율 선(순이익률, 영업이익률, 부채비율) | `--vz-line` | `--g300` |
| 나머지 묶음(그 밖의 주주 등) | `--vz-rest` | `--g600` |

- 묶음 막대(주주 구성)는 파랑 → 주황 → 청록 → 회색 순서다. 매출 구성처럼 이름이 막대 옆에 붙는 목록은 파랑 한 색이다.
- 그래프의 파랑·보라는 악재·AI와 비슷하지만, 그래프 안에서만 쓰고 늘 범례가 붙는다. 그래프 밖(글자, 칩, 칸의 면)에는 그래프 색을 쓰지 않는다. AI 요약 카드가 있는 공시 탭에는 그래프가 없다.
- 마지막 분기를 색으로 따로 밝히지 않는다.
- 색 조합은 색약 구분 검사를 통과한 값이다. 색을 바꾸면 다시 검사한다.

## 4. 글자

- 글꼴: Pretendard(가변 굵기). 한글과 영문·숫자의 모양이 고르고 화면용으로 만들어져 모던·테크 분위기에 맞는다. 없으면 시스템 글꼴(-apple-system, Apple SD Gothic Neo, 맑은 고딕) 순서다. 실제 화면에서는 글꼴 파일을 직접 두고 쓴다.
- **글자는 아래 여덟 역할만 쓴다.** 크기는 13·15·17·20·28px(폭 600px 이하에서 회사 이름 24)과 랜딩 전용 44px뿐이다. 굵기는 400·600·700·800뿐이다.

| 역할 | 크기 / 굵기 / 줄 간격 | 색 | 쓰는 곳 |
|---|---|---|---|
| 화면 제목 | 28 / 800 / 1.3 | 본문 | 회사 이름, 전체 공시 화면의 제목 |
| 큰 값 | 20 / 800 / 1.3 | 본문 | 패널 제목 |
| 카드 제목 | 17 / 700 / 1.4 | 본문 | 카드 제목, 카드 안 묶음 제목(수익성, 주주 구성 등), 상태 안내의 제목, 로고 글자. **회사 이름 옆 판단 이름은 같은 크기에 800**(호재·악재·중립·보조색) |
| 줄 제목 | 15 / 600 / 1.5 | 본문 | 목록 한 줄의 제목(타임라인의 공시 이름, 뉴스 제목), 탭 글자, 버튼 글자, 요약 띠의 값, 빈 상태의 제목 |
| 본문 | 15 / 400 / 1.6 | 본문 | 문단, AI 요약, 묶음의 한 줄 결론 |
| 칸 제목 | 13 / 700 / 1.5 | 보조(AI 칸의 이름표는 보라) | AI 칸의 이름표, 전체 공시의 연도 |
| 라벨 | 13 / 600 / 1.5 | 보조·뜻 색 | 칩, 세그먼트, 글자형 버튼 |
| 메타 | 13 / 400 / 1.5 | 보조(고지·날짜) 또는 옅은 색(출처·언론사) | 한 줄 위·아래의 보조 정보, 요약 띠의 이름, 표 |

- 한 카드 안의 글자 위계는 세 단계까지다: 카드 제목 / 줄 제목·본문 / 칸 제목·라벨·메타.
- 회사 이름이 화면에서 가장 큰 글자이고, 판단 이름은 한 단계 작다. 판단은 색으로 이미 강조된다.
- 자간은 −0.01em, 화면 제목 −0.03em, 큰 값과 카드 제목 −0.02em, 13px 글자는 0이다.
- 숫자는 `tabular-nums`로 자리를 맞춘다.
- 금액은 읽기 쉬운 단위로 쓴다: 1조 원 이상은 "11.3조 원", 그 아래는 "3,900억 원". "2,373,000억"처럼 쓰지 않는다. 한 화면 안에서 단위를 섞지 않는다("조"와 "조 원").
- 한글은 `word-break: keep-all`로 단어 중간에서 줄을 바꾸지 않고, 긴 공시 이름은 `overflow-wrap: anywhere`로 넘치지 않게 한다.
- **공시 이름은 DART 원문 그대로 쓴다.** 줄이거나 고치지 않는다. 타임라인과 전체 공시의 줄은 공시 이름이고, 무슨 일인지 쉬운 말 한 줄은 공시 패널의 제목이다(8절).

## 5. 모양과 간격

- **간격은 4px 단계 일곱 개만 쓴다:** `--s1` 4 / `--s2` 8 / `--s3` 12 / `--s4` 16 / `--s6` 24 / `--s8` 32 / `--s12` 48px.

| 간격 | 쓰는 곳 |
|---|---|
| 4 | 아이콘과 13px 글자 사이, 회사 이름과 그 아래 메타 사이, 탭 줄 양옆 |
| 8 | 아이콘과 15px 글자 사이, 칩 안 여백, 버튼끼리, 한 줄 결론 위 |
| 12 | 목록 줄 안 여백, 상단 바 위아래, 회사 이름과 판단 사이 |
| 16 | 카드 안의 칸 안 여백, 화면 양옆 여백, 버튼 양옆 여백 |
| 24 | 카드 안 여백, 카드 사이, 머리·탭·내용 사이, 탭 글자 사이, 패널 안 여백 |
| 32 / 48 | 화면 위·카드 안 묶음 사이 / 화면 아래 여백 |

- **테두리가 있는 모양은 모두 둥근 사각형 한 가족이고, 모서리는 세 가지만 쓴다:** `--r-lg` 16px(카드, AI 요약 카드, 패널의 위쪽 모서리) / `--r-md` 12px(카드 안의 칸, 버튼, 세그먼트, 입력창, 목록 줄, 자동완성, 로고 칸) / `--r-sm` 8px(높이 24px의 칩). **양끝이 반원인 알약 모양은 쓰지 않는다**(카드 안에서 둥근 사각형과 섞이면 모양이 두 종류로 보여 통일감을 해친다). 타임라인의 점은 표시라 둥근 점이고, 그래프의 막대는 그림이라 예외다.
- 부품 높이: 누르는 것 44px(세그먼트만 36px, 손가락으로 누르는 기기에서는 44px), 탭 48px, 칩 24px.
- **묶음은 면으로 나눈다.** 카드는 회색 단계 925 면이고 테두리는 1px `--line`뿐이다. 카드 안의 칸은 `--surface` 면으로 한 단계 들인다. 그 밖의 선은 목록·표의 줄 나눔(`--line`)과 타임라인의 세로 선에만 쓴다. 왼쪽 세로 막대 장식은 쓰지 않는다.
- 레이아웃: **화면 폭과 상관없이 한 단**(최대 폭 640px, 가운데)이다. 두 단으로 나누면 판단과 나머지가 동시에 눈에 들어와 시선이 흩어지고, 두 단의 길이가 달라 한쪽이 빈다. 양옆 여백 16px 이상(노치가 있는 기기는 안전 영역만큼 더). 카드 사이 24px, 카드 안 여백 24px(폭 600px 이하에서는 위아래 24 / 양옆 16px), 목록 한 줄의 안 여백 12px.

## 6. 부품과 상태

### 6-1. 누를 수 있는 부품

실제 `button`, `a`만 쓴다. **hover는 지금 면보다 한 단계, 누름·선택은 두 단계 밝게** 하고, 크기와 위치는 바꾸지 않는다(scale, 이동 없음). 색 전환은 0.2초.

| 부품 | 기본 | hover | 누름 | 선택 | 포커스 | 쓸 수 없음 |
|---|---|---|---|---|---|---|
| 주 버튼 (밝은 면. 한 화면·패널에 하나: 불러오기 오류의 다시 불러오기) | 200 면, 950 글자 | 300 면 | 400 면 | — | 공통 | 공통 |
| 보조 버튼 (분석 실패의 다시 불러오기, DART에서 보기, 원문 기사 보기) | 900 면, 700 테두리 | 800 면, 600 테두리 | 700 면 | — | 공통 | 공통 |
| 글자형 버튼 (이전·다음, 전체 공시·전체 뉴스 보기, 돌아가기) | 면 없음, 보조 글씨 | 900 면, 본문 글씨 | 800 면 | — | 공통 | 공통 |
| 아이콘 버튼 (닫기, 44px 정사각) | 면 없음 | 900 면 | 800 면 | — | 공통 | 공통 |
| 탭 (공시 · 개요 · 재무 · 뉴스) | 보조 글씨 | 본문 글씨 | — | 본문 글씨 + 2px 흰 밑줄 | 공통 | — |
| 세그먼트 (재무제표 종류, 전체 공시의 판정) | 900 면, 700 테두리, 보조 글씨 | 800 면, 600 테두리, 본문 글씨 | 700 면 | 200 면, 950 글자, 굵게 | 공통 | 공통 |
| 입력창 (검색) | 900 면, 800 테두리 | 700 테두리 | — | — | 600 테두리 + 공통 | 공통 |
| 목록 한 줄 (타임라인, 뉴스, 전체 공시, 실적 발표 기록) | 면 없음 | 900 면 | 800 면 | 800 면(패널에 열린 줄. 뉴스 줄은 패널을 열지 않아 없음) | 공통 | — |
| 글자 링크 (패널의 DART 원문 줄, 홈페이지) | 보조 글씨, 700 밑줄 | 본문 글씨, 400 밑줄 | — | — | 공통 | — |

- **포커스(공통):** 2px `--focus` 테두리, 3px 띄움. **절대 빼지 않는다.**
- **쓸 수 없음(공통):** 투명도 .4, 커서 기본, 눌러도 반응 없음(예: 가장 오래된 공시의 "이전 공시").
- 누를 수 없는 카드에는 hover를 두지 않는다.
- **패널을 여는 줄에는 끝에 꺾쇠(">")를 달지 않는다.** 오른쪽 꺾쇠는 옆에서 새 화면이 열릴 것처럼 보이는데, 패널은 아래에서 올라온다. 누를 수 있다는 표시는 마우스를 올렸을 때의 면과 커서가 맡는다. 새 창으로 여는 링크의 바깥 링크 아이콘은 남긴다.

### 6-2. 표시 부품 (누를 수 없음, 상태 없음)

- **칩**(24px, 모서리 8, 라벨 글자): 호재·악재·중립(기호 없이 글자. 면은 `--card` 위에 옅은 색을 겹쳐 고정), 일반 칩(700 테두리. 머리의 "업데이트 지연"). AI는 칩을 쓰지 않고 AI 칸의 이름표(칸 제목 글자, 보라)로 표시한다.
- **판단 이름**(카드 제목 크기 800, 상자 없음): 다섯 단계 + 판단 보류(보조색 글자).
- **카드**(925 면, 800 테두리, 16), **AI 요약 카드**(보라 6% 면, 32% 테두리, 16), **카드 안의 칸**(900 면, 12, 안 여백 16), **AI가 쓴 글의 칸**(패널 안. 보라 6% 면, 32% 테두리, 12).
- **요약 띠**: 카드 안의 칸(900) 하나에 이름(메타)과 값(줄 제목)을 여러 칸 나란히. 개요의 기본 사항, 재무·실적의 첫 줄, 주식 수.
- **패널**: 유리(3-2-1), 아래에서 올라오는 시트(8절).

### 6-3. 아이콘

- **24 칸에 직접 그린 선 아이콘**이다. 선 굵기는 크기와 상관없이 1.5px(`vector-effect: non-scaling-stroke`), 끝과 꺾임은 둥글게. 받은 참고 자료의 아이콘을 옮기지 않는다.
- 크기: 13px 글자 옆은 16px, 버튼·입력창(15px 글자)은 20px. 색은 글자색을 따른다.
- 세트: **다음**(오른쪽 꺾쇠. 패널의 다음 공시, 다른 화면으로 가는 "전체 공시 보기"·"전체 뉴스 보기"), **이전**(왼쪽 꺾쇠. 이전 공시, 돌아가기), **바깥 링크**(상자 밖으로 나가는 화살표. DART 원문, 뉴스 줄(원문 기사), 홈페이지, 새 창), **닫기**(엑스), **다시 불러오기**(둥근 화살표), **검색**(돋보기).
- 호재·악재·중립에는 기호를 붙이지 않는다(3-2). 기능 아이콘도 ›·↗ 같은 글자 기호가 아니라 위 세트로 그린다.
- 아이콘은 화면 읽기에서 숨기고(`aria-hidden`), 아이콘만 있는 버튼에는 이름(`aria-label`)을 붙인다. 새 창으로 여는 링크에는 "(새 창)"을 화면 읽기용으로 붙인다.

### 6-4. 화면 상태

**판단의 상태 다섯 가지**: 호재 / 악재 / 중립 / 판단 보류(판단 이름을 보조색으로. 공시 탭의 첫 카드는 AI 요약 대신 보통 카드에 판단을 내리지 않은 이유 한 문장) / **업데이트 지연**(분석 실패와 수집 지연을 같은 방식으로: 머리의 기준일이 지난 날이 되고 그 옆에 일반 칩 "업데이트 지연"(모든 탭에서 보임), 공시 탭 첫 카드의 글을 투명도 .6으로 흐리게 보여주며, 카드 아래에 원인 한 줄("공시 분석이 끝나지 않아…" 또는 "공시를 아직 받지 못해…")과 "다시 불러오기" 보조 버튼).

업데이트 지연을 띄우는 조건은 달력이 아니라 **마지막 예정 작업(공시 수집 또는 저녁 분석)이 실패로 끝났는가**다. 주말·공휴일처럼 작업이 없는 날에는 기준일이 지난 날이어도 띄우지 않는다.

**화면 전체의 상태** (데모 화면 아래 "데모 화면 상태"로 볼 수 있다)

| 상태 | 표현 |
|---|---|
| 불러오는 중 | 실제 배치(머리, 탭, AI 요약 카드, 타임라인)와 같은 자리에 900 면(자리 표시). 1.6초에 한 번 옅어진다. 화면 읽기에는 "불러오는 중이에요"를 알리고 `aria-busy`를 켠다 |
| 불러오기 오류 | 카드 하나에 카드 제목("회사 정보를 불러오지 못했어요"), 원인과 다음 행동 한 줄, 주 버튼 "다시 불러오기"와 보조 버튼 "DART에서 보기". 빨강을 쓰지 않는다(빨강은 호재) |
| 공시가 없는 회사 | 판단 보류("아직 모은 공시가 없어…"), 타임라인·개요·재무·뉴스는 빈 상태 칸 |
| 검색 결과 없음 | 자동완성 자리에 검색 아이콘 + "‘입력한 말’에 맞는 회사가 없어요" + 찾는 방법 한 줄 |
| 분석 실패 · 수집 지연 | 위의 판단 상태(업데이트 지연) |
| 뉴스를 불러오지 못함 | 뉴스 탭·전체 뉴스 화면에 빈 상태 칸 "뉴스를 불러오지 못했어요"와 "다시 불러오기". 나머지 탭은 그대로 |

**빈 상태 칸**: 카드 안의 칸(900 면) 안에 줄 제목(왜 없는지)과, 필요하면 메타(언제 생기는지).

**비어 있거나 없는 것은 이유를 말한다.** "최근 30일 호재·악재 공시가 없어요", "아직 모은 실적이 없어요. 분기보고서나 잠정실적 공시가 나오면 채워져요"처럼 왜 없는지와 언제 생기는지를 쓴다. 공시 패널의 요약 자리는 중립 공시면 비워 두고(요약하지 않는다), 호재·악재인데 요약이 아직 없으면 "AI 요약 · 준비 중"을 둔다.

## 7. 움직임

- 기본 전환: 0.2초, `cubic-bezier(0.4, 0, 0.2, 1)`. 이 하나만 쓴다.
- 쓰는 곳: 색·테두리 전환, 패널 열림(아래에서 올라옴), 막 나타남, 다시 불러온 화면을 1.2초 밝혔다가 원래대로, 불러오는 중 자리 표시가 1.6초에 한 번 옅어짐.
- 쓰지 않는 것: 크기 변화, 흔들림, 튀는 곡선, 스크롤에 따라 움직이는 연출, 저절로 도는 슬라이드, 숫자 올라가는 효과.
- 사용자가 움직임 줄이기(`prefers-reduced-motion`)를 켜 두었으면 전환과 애니메이션을 모두 끈다.

## 8. 화면 패턴

### 8-1. 종목 화면의 뼈대

- **머리 → 탭 → 탭 내용**이다. 넓은 화면에서도 같은 순서의 한 단이다.
- **머리:** 첫 줄에 회사 이름과 판단 이름(색 글자)을 나란히, 둘째 줄에 "종목코드 · 시장 · 기준일"(메타). 업데이트 지연이면 기준일 옆에 칩 "업데이트 지연"(6-4). 회사 이름이 길어 한 줄에 들어가지 않으면 판단이 이름 바로 아래 줄로 내려간다. 판단은 머리에만 두어 어느 탭에서든 보인다.
- **탭:** 회사 머리 바로 아래 "공시 · 개요 · 재무 · 뉴스". 처음 열리는 탭은 공시다(판단의 근거가 이 탭에 있다). 탭 줄은 상단 바 아래에 붙어 따라오고(바탕색 면, 아래 1px `--line`), 선택된 탭은 흰 글자와 2px 흰 밑줄이다. 탭에는 건수를 붙이지 않는다. 탭마다 주소가 붙는다(`PLAN.md` 5절). 탭을 바꿀 때 탭 줄이 위에 붙어 있었으면 새 탭의 처음이 탭 줄 바로 아래에 오게 한다.
- **탭 이름이 곧 제목이다.** 탭 안에 탭 이름과 같은 말의 카드 제목을 또 두지 않는다(공시 탭과 개요 탭의 카드는 제목이 없고, 뉴스 카드의 제목은 화면 읽기에만 남긴다). 재무 탭은 "실적"과 "재무" 두 카드라 제목을 둔다.
- **카드 제목은 짧은 명사형**이다: "실적", "재무", "수익성". 질문형("…어때요?")을 쓰지 않는다.
- **로고:** 모서리가 둥근 사각 칸(32px, 모서리 12px)을 `--text` 면으로 채우고, 겹친 층 아이콘(18px)을 `--bg` 색으로 넣는다. 옆에 "기업 인사이트"(카드 제목 글자).
- **상단 바:** 로고와 검색창(왼쪽에 검색 아이콘). 검색창은 최대 폭 420px이고 넓은 화면에서도 끝까지 늘리지 않는다.
- 숫자 점수는 공개 화면에 보이지 않는다. 판단은 다섯 단계 이름으로 보여준다.
- 판단 추이 그래프는 지금 화면에 두지 않는다(`PLAN.md` 10절).

### 8-2. 공시 탭

- **AI 요약 카드 → 공시 타임라인 카드** 순서다.
- **AI 요약 카드:** 카드 전체가 AI가 쓴 글의 칸이다(보라 테두리, 옅은 보라 면, 위쪽에 보라 이름표 "AI 요약"). 최근 공시가 판단을 어느 쪽으로 이끄는지 문장으로 쓴다. 아래에 줄 나눔선을 두고 고지 한 줄. 판단 이름과 기준일은 머리에 있으므로 카드에 다시 쓰지 않는다.
- **공시 타임라인:** 세로 선 하나를 따라 시간이 흐른다. 위가 앞날, 흰 큰 점이 오늘, 아래로 갈수록 과거다. 카드 제목은 두지 않는다(오늘 점과 "예정" 표시가 시간을 알려 준다).
  - 보이는 공시는 **최근 30일의 호재·악재 공시**(판단에 쓴 공시)뿐이다. 중립 공시와 30일보다 오래된 공시는 카드 아래 "전체 공시 보기"(다른 화면)에서 본다. 30일 밖 공시를 흐리게 덧붙이지 않는다.
  - 점의 색은 호재(빨강)·악재(파랑), **점의 크기는 영향**(작음 8 / 보통 11 / 큼 15px), 예정은 빈 점, 오늘은 흰 큰 점(14px)이다.
  - **공시 사이의 세로 간격은 날짜 차이만큼** 벌어진다(하루 5px, 최대 14일치). 줄 나눔선과 날짜 묶음 제목은 두지 않는다.
  - 한 줄은 두 줄이다: 첫 줄(메타) "날짜 요일 · 호재/악재"(호재·악재는 색 글자), 둘째 줄(줄 제목) **DART 공시 이름**(원문 그대로). **같은 날 공시가 여럿이면 둘째 줄부터 날짜 자리를 비운다**(자리는 남겨 호재·악재 글자가 줄을 맞춘다. 화면 읽기에는 날짜를 숨긴 글자로 준다). 전체 공시 화면도 같다. 최근 3일 안의 가장 새 공시에는 이름 앞에 "새". 쉬운 말 한 줄, 핵심 수치, 요약은 줄에 쓰지 않고 패널에서 보여준다.
  - 앞날(예정)은 공시에 적힌 앞으로의 날짜다(빈 점, "날짜 · 예정 · D-n", 이름은 보조색). MVP 뒤에 더한다(`PLAN.md` 11절).
  - 줄을 누르면 공시 패널이 열린다. 패널이 열린 동안 그 줄은 선택 상태로 보인다.
  - 최근 30일에 호재·악재 공시가 없으면 오늘 점 아래에 빈 상태 칸 "최근 30일 호재·악재 공시가 없어요".

### 8-3. 개요 탭

- 회사가 누구인지와 공시를 읽을 때 함께 볼 점을 모은다. 한 카드 안에 위에서 아래로:
  1. **한 줄 소개**(본문): 설립 연도와 주요 사업명(공공데이터 기업기본정보)으로 만든 문장. 주요 사업명이 비면 줄을 숨긴다
  2. **기본 사항**(요약 띠): 업종(같은 곳의 업종명), 대표이사, 설립일, 결산월, 홈페이지(바깥 링크). 값이 빈 칸은 숨긴다
  3. **매출 구성**: 사업 부문마다 이름 옆 가로 막대(파랑 한 색)와 비율. 음수(부문 간 거래 제거)는 막대 없이 숫자만(옅은 색). **MVP에서는 숨긴다.** 데모의 블록은 넣을 때의 모양이고, MVP 뒤 재무제표 원본(XBRL)의 영업부문 주석으로 채운다
  4. **주주 구성**: 한 줄 결론 → 한 줄 막대(최대주주 쪽, 자기주식, 소액주주, 그 밖) → 범례 표(지금 %와 1년 전 %)
  5. **주식 수 변화**(최근 3년): 한 줄 결론 → 요약 띠(지금 발행주식, 3년 전, 아직 바뀌지 않은 사채가 모두 주식으로 바뀌면) → 유상증자·전환사채 발행 같은 사건 목록. "모두 바뀌면"은 최근 정기보고서의 미상환 사채 표 합계로 "9월 말 기준"처럼 기준일을 붙인다. **MVP에서는 이 칸을 빼고** 지금 발행주식·3년 전만 둔다
  6. **주의할 점**(최근 3년): 한 줄 결론 → 줄 목록(감사의견, 관리종목·투자주의 지정, 불성실공시법인 지정, 소송 제기). 문제가 없는 줄은 담담하게, 문제가 있는 줄만 악재 색
  7. 출처 한 줄
- 넣지 않는 것: 배당, 시가총액·PER 같은 시세로 계산하는 값, 직원·급여, 자회사 목록.

### 8-4. 재무 탭

- **"실적" 카드 → "재무" 카드** 순서다.
- **실적:** 요약 띠(최근 발표일, 발표 영업이익, 1년 전 대비) → 발표 기록(분기 · 발표일 · 영업이익 · 1년 전 대비). 발표 기록의 줄을 누르면 그 잠정실적 공시 패널이 열린다. 증권사 예상치와 비교하지 않는다.
- **재무:** 요약 띠(부채비율, 유동비율, 이자보상비율) → 수익성 · 성장성 · 안정성 묶음 → 재무제표.
  - **이자보상비율** = 영업이익 ÷ 이자(연초부터 그 분기까지 누적). 이자는 현금흐름표의 이자비용 줄, 없으면 이자 지급액. 영업이 적자면 "영업적자", 이자가 0이면 "이자 없음". 숨기는 경우: 유동자산 계정이 없는 회사(금융업), 이자 지급액이 금융비용 전체보다 큰 회사(금융 부문의 이자가 원가에 섞여 배율이 실제보다 낮게 나온다).
  - **계정이 없는 칸은 숨긴다**(업종을 따로 가리지 않는다). 매출액이 없으면(금융업 일부, 매출이 없는 회사) 수익성·성장성 그래프는 이익 막대만 두고 비율 선을 뺀다. 유동자산이 없으면 유동비율을 뺀다. 부채비율은 그대로 둔다(금융업은 1,000%대가 나올 수 있다). 업종에 맞춘 그래프는 MVP 뒤.
  - 묶음마다 **한 줄 결론(본문, 코드가 숫자로 만든 문장) → 그래프 → 표**다.
  - 그래프는 최근 8개 분기의 **막대 둘(같은 눈금) + 비율 선(오른쪽 눈금)**이다. 수익성은 매출액·순이익 + 순이익률, 성장성은 매출액·영업이익 + 영업이익률, 안정성은 총자본·총부채 + 부채비율. 색은 3-4. 범례는 그래프 바로 아래.
  - 표는 같은 수치를 분기별로(맨 왼쪽 칸 고정, 옆으로 밀기, 처음에는 최근 분기가 보이게). 1년 전 대비 증감은 빨강(+)·파랑(−).
  - 재무제표는 세그먼트(손익계산서 · 재무상태표 · 현금흐름표)로 고르는 최근 4개 분기 표.
- 비교 기준은 직전 분기가 아니라 **1년 전 같은 분기**다(계절 차이를 피한다). 단위는 "조 원"으로 통일한다.
- **재무 그래프는 Chart.js로 그린다.** canvas는 CSS 변수를 읽지 못하므로 그릴 때 토큰의 계산된 값을 넘긴다. 칸 너비만 정하면 되는 막대(매출 구성, 주주 구성)는 라이브러리 없이 그린다.

### 8-5. 뉴스 탭

- **뉴스는 저장하지 않는다.** 뉴스 탭을 열 때 네이버 뉴스 검색을 회사 이름으로 불러 **받은 그대로**(최신순) 보여준다. 거르거나 순서를 바꾸거나 사이에 다른 것을 끼우지 않는다. 그래서 회사와 무관한 기사가 섞일 수 있다. 뉴스는 AI에 넣지 않고(요약·분류 없음) 판단 점수에도 넣지 않는다.
- 날짜 묶음 없이 한 목록이다. 줄 = 제목(줄 제목) / "언론사 · 시각"(메타, 옅은 색) + 바깥 링크 아이콘. 검색 결과에는 언론사 이름이 없으므로 원문 주소의 도메인을 언론사 이름 표로 바꾼다. 표에 없는 도메인은 도메인 그대로 쓴다. 시각은 오늘이면 "2시간 전", 어제면 "어제 17:20", 그 전은 "11.04 15:30".
- **줄을 누르면 원문 기사로 바로 간다**(새 창). 뉴스 패널은 없다.
- 최근 10건만 보이고, 카드 아래 "전체 뉴스 보기"(다른 화면, 8-7)로 나머지를 본다. 공시 탭의 "전체 공시 보기"와 같은 모양이다. 맨 아래에 출처 한 줄 "네이버 뉴스 검색결과"(모양은 네이버 BI 가이드를 따른다).
- 불러오지 못하면 빈 상태 칸 "뉴스를 불러오지 못했어요"와 다시 불러오기(6-4).
- 뉴스 탭에는 뉴스만 둔다. 같은 소식의 공시와 잇는 방법은 정하지 않았다.

### 8-6. 패널 (공시 한 건)

- **아래에서 올라오는 시트**다. 넓은 화면에서는 본문 카드와 같은 너비(`--page`에서 좌우 여백을 뺀 값)로 가운데에서 올라오고 높이는 화면의 80%까지, 폭 640px 이하에서는 화면 폭 전체에 88%까지다. 위쪽 모서리만 둥글다(16). 어디서 누르든 같은 패널이 열린다(타임라인, 전체 공시, 실적 발표 기록).
- 머리: 회사 이름(메타)과 닫기 버튼. 바닥: 이전·다음(날짜순, 이전 = 더 오래된 것).
- **공시 패널 내용 순서:** 호재·악재 칩과 영향(작음·보통·큼) → 제목(무슨 일인지 쉬운 말 한 줄, 큰 값) → **"날짜 · DART 공시 이름" 줄이 곧 원문 링크**(바깥 링크 아이콘, 새 창. 출처 표시와 원문 링크를 한 줄로) → AI 3줄 요약 → 고지(요약이 있을 때만).
  - 요약은 평문이다. 금액·수치를 굵게 하지 않고, 핵심 수치 칸을 따로 두지 않는다.
  - 중립 공시는 요약하지 않으므로 요약 자리를 비운다. 호재·악재인데 요약이 아직 없으면 보라 이름표 "AI 요약"과 회색 "준비 중".
- 열면 포커스가 닫기 버튼으로 가고 뒤 화면은 누를 수 없게 막는다. Esc, 바깥 막 누르기, 닫기 버튼, 뒤로 가기로 닫힌다. 닫으면 포커스가 누른 줄로 돌아간다.
- 공시마다 주소(접수번호)가 붙는다. 패널 안의 이전·다음은 주소를 바꾸기만 하고 뒤로 가기 기록을 쌓지 않는다.

### 8-7. 전체 공시 화면과 전체 뉴스 화면

두 화면은 같은 틀이다: 맨 위에 "회사 이름으로 돌아가기"(글자형 버튼, 이전 아이콘)와 화면 제목, 한 카드 안에 거르기 → 목록 → 쪽 넘김(20건씩). 뒤로 가기로 종목 화면(그 탭)에 돌아간다. 전체 공시는 건수와 연도 묶음 제목이 있고 줄을 누르면 패널이 열린다. 전체 뉴스는 받은 그대로 보여주므로 건수·묶음 제목이 없고 줄을 누르면 원문 기사로 간다.

**전체 공시**

- 공시 타임라인의 "전체 공시 보기"로 가는 다른 화면이다. 맨 위에 "회사 이름으로 돌아가기"(글자형 버튼)와 제목 "전체 공시".
- 거르기: 공시 이름 찾기(입력창), 판정(세그먼트: 전체·호재·악재·중립), 분류, 연도. 그 아래 건수.
- 목록은 연도별로 나누고, 줄 = 날짜 | 공시 이름 / "호재·악재·중립 · 분류". 20건씩 쪽을 넘긴다. 모아 둔 기간보다 오래된 공시는 맨 아래 "DART에서" 링크로.

**전체 뉴스**
- 뉴스 탭의 "전체 뉴스 보기"로 가는 다른 화면이다. 제목 "전체 뉴스".
- 찾기(입력창 "뉴스 찾기")만 있다. 찾기는 "회사 이름 + 찾는 말"로 검색을 다시 부른다. 언론사 거르기와 월별 묶음은 두지 않는다(받은 결과를 고치지 않는다).
- 줄은 뉴스 탭과 같다(제목 / 언론사 · 시각, 누르면 원문 기사). 20건씩 쪽을 넘기고 쪽마다 검색을 부른다. 검색 한 번으로 볼 수 있는 범위는 약 1,100건이다. 맨 아래에 "네이버 뉴스 검색결과".

## 9. 접근성

- 글자 대비 4.5 : 1 이상(3-3).
- 손가락으로 누르는 기기에서 누르는 곳은 44px 이상이다.
- 누르는 것은 실제 `button`과 `a`로 만든다. `div`에 클릭을 달지 않는다.
- 탭은 `tablist`·`tab`·`tabpanel` 역할을 쓰고, 좌우 방향키로 옮긴다.
- 그래프의 수치는 바로 아래 표에도 있다. 그래프에는 무엇을 그렸는지 이름을 붙인다.
- 타임라인 점의 크기(영향)는 화면 읽기에 "영향 작음·보통·큼"으로 알린다.
- 색만으로 뜻을 전하지 않는다(3-2).

## 10. 문구

- 해요체로 쓴다. 짧게, 사실만. 패널 제목의 쉬운 말 한 줄은 명사로 끝내도 된다("…13% 증가", "…취득 결정").
- 매수·매도·추천·목표가·예측처럼 읽히는 표현과 시세를 안내하는 표현을 쓰지 않는다.
- 판단은 "최근 공시 기준"이다. 머리의 기준일이 그 시점을 밝힌다.
- 오류는 원인과 다음 행동을 쓰고 사과하지 않는다. 예: "11.06 공시 분석이 끝나지 않아 11.05 판단을 보여주고 있어요. 새 공시는 다음 분석 때 반영돼요."
- AI 요약 카드, 요약이 있는 공시 패널, 화면 아래에 "AI 요약은 틀릴 수 있으며 투자 권유가 아니에요" 고지를 둔다. 공시·재무의 출처(DART)와 뉴스의 출처(네이버 뉴스 검색결과, 기사마다 언론사)를 밝힌다.

## 11. 라이트 모드 (이후)

지금은 어두운 토큰 한 벌만 있다(`color-scheme: dark`). 라이트 모드는 3-1의 토큰 블록을 하나 더해 붙인다(회색 단계표를 밝은 쪽으로 뒤집고, 호재·악재·AI·그래프 색은 밝은 바탕에서 대비를 다시 계산한다). 시스템 설정을 따를지 전환 버튼을 둘지는 붙일 때 정한다.
