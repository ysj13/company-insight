모든 화면이 쓰는 색, 글자, 간격, 부품과 상태, 아이콘, 화면 상태를 한곳에 모았어요. 규칙의 이유는 DESIGN.md, 실제 화면은 데모에서 볼 수 있어요.

색그래프 색대비글자간격·모서리부품과 상태표시 부품머리·탭·타임라인패널아이콘화면 상태

회색 단계표와 색 토큰

검정·회색은 한 계열의 단계표 값만 써요. 면은 안으로 들어갈수록 한 단계씩 밝아져요: 바탕 950 → 카드 925 → 카드 안의 칸 900 → 선택 800. 뜻이 있는 색은 호재·악재·AI 셋뿐이에요.

그래프 색

지표마다 색을 고정해요. 매출액은 어느 그래프에서나 파랑이고, 비율 선은 모두 밝은 회색이에요. 그래프 안에서만 쓰고 늘 범례를 붙여요. 글자·칩·칸의 면에는 쓰지 않아요. 재무 그래프는 Chart.js로 그려요(canvas는 CSS 변수를 못 읽어서 그릴 때 계산된 색을 넘겨요).

성장성막대 둘(같은 눈금) + 비율 선(오른쪽 눈금)

매출액영업이익영업이익률

라이브러리 없이 그리는 막대칸 너비만 정하면 되는 것

  • 가전·스마트폰·네트워크54%
  • 메모리·시스템 반도체38%
  • 부문 간 거래 제거-7%

매출 구성은 파랑 한 색(이름이 막대 옆에 붙어요). 주주 구성은 파랑 → 주황 → 청록 → 회색 순서예요.

대비 표

이 페이지가 토큰 값으로 WCAG 식을 직접 계산한 값이에요(반투명 색은 아래 면에 합성해서 계산). 글자는 4.5:1, 포커스 테두리와 그래프 색은 3:1 이상이어야 해요. 쓸 수 없는 상태(투명도 .4), 분석 실패 때 흐린 지난 요약(.6), 주주 구성의 "그 밖" 칸(회색, 범례에 이름과 숫자가 있음)은 예외예요.

조합보기대비기준

글자 단계

Pretendard, 줄 간격 1.6(제목 1.3~1.4), 숫자는 자리 맞춤(tabular-nums). 역할은 아래 여덟 가지뿐이고, 크기는 13·15·17·20·28(폭 600px 이하의 회사 이름 24)만 써요. 회사 이름 옆 판단 이름은 카드 제목 크기에 굵기 800이에요.

간격과 모서리

간격은 4px 단계 일곱 개만 써요. 테두리가 있는 모양은 모두 둥근 사각형 한 가족이고 모서리는 세 가지예요: 큰 면 16, 안쪽 것 12, 작은 칩 8. 양끝이 반원인 알약 모양은 쓰지 않아요(카드 안에서 사각형과 섞이면 모양이 둘로 보여요). 타임라인의 점은 표시라 둥근 점이에요.

16

--r-lg 카드, AI 요약 카드, 패널의 위쪽 모서리

12

--r-md 안쪽 칸·요약 띠, 버튼, 세그먼트, 입력창, 목록 줄, 자동완성, 로고

8

--r-sm 높이 24px의 칩(호재·악재·중립, 뉴스)

누를 수 있는 부품과 상태

hover는 지금 면보다 한 단계, 누름·선택은 두 단계 밝게 해요. 크기와 위치는 바뀌지 않고 색만 바뀌어요(0.2초). 포커스 테두리는 절대 빼지 않아요. 주 버튼은 한 화면(패널)에 하나만 둬요. 아래 표는 각 상태를 멈춰서 보여줘요. 실제로 마우스를 올리고 눌러 볼 수도 있어요.

부품기본hover누름선택포커스쓸 수 없음

패널을 여는 줄에는 끝에 꺾쇠(">")를 달지 않아요. 오른쪽 꺾쇠는 옆에서 새 화면이 열릴 것처럼 보이는데 패널은 아래에서 올라와요. 세그먼트는 같은 내용을 다른 범위로 보는 선택(재무제표 종류, 전체 공시의 판정)에만 써요.

표시 부품 (누를 수 없음)

칩, 판단 이름, 카드, 칸은 누를 수 없어서 hover·누름 상태가 없어요. 누를 수 없는 것에 hover를 두면 눌리는 것처럼 보이기 때문이에요.

칩: 호재·악재·중립과 뉴스. 한 줄에 하나까지

판단 이름: 회사 이름 옆 색 글자(17 / 800). 상자·알약·눈금 없음. 다섯 단계 + 판단 보류(보조색)

카드

925 면, 1px 800 테두리, 모서리 16, 안 여백 24(폭 600px 이하 24·16). 그림자 없음.

공시 탭의 첫 카드. 카드 전체가 AI가 쓴 글의 칸이에요(보라 1px 테두리, 보라 6% 면).

머리, 탭, 공시 타임라인

종목 화면은 머리 → 탭 → 탭 내용이에요. 판단은 머리에만 두어 어느 탭에서든 보여요. 탭 줄은 상단 바 아래에 붙어 따라오고(이 페이지에서는 멈춰 둠), 선택된 탭은 흰 글자와 2px 흰 밑줄이에요.

    원문 기사 보기

    뉴스 패널: "뉴스" 칩 → 제목 → 언론사 · 시각 → AI 3줄 요약 → 고지 → 원문 기사 보기. 뉴스 요약은 보류이고, 이 모양은 요약을 넣을 때의 모양이에요(넣지 않기로 하면 요약 칸과 고지를 빼요). 요약이 없는 기사는 "준비 중".

    아이콘

    24 칸에 직접 그린 선 아이콘이에요. 선 굵기는 크기와 상관없이 1.5px, 끝은 둥글게. 글자 옆(13px)에는 16px, 버튼·입력창(15px)에는 20px로 써요. 아이콘만 있는 버튼에는 이름(aria-label)을 붙이고, 아이콘은 화면 읽기에서 숨겨요. 호재·악재·중립에는 기호를 붙이지 않아요. "호재", "악재" 글자와 색으로 뜻을 전해요(주가 등락 표시처럼 읽히지 않게, 작은 기호의 가독성 문제도 없게).

    화면 상태

    비어 있거나 실패한 상태도 이유와 다음 행동을 말해요. 오류는 빨강을 쓰지 않아요(빨강은 호재). 데모 화면 아래의 "데모 화면 상태"로 실제 배치에서 볼 수 있어요.

    불러오는 중

    실제 배치(머리, 탭, AI 요약 카드, 타임라인)와 같은 자리에 900 면. 1.6초에 한 번 옅어져요(움직임 줄이기면 멈춤).
